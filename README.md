# RDAE 2027 Website

Single-page responsive conference website for:

International Conference on Research and Developments in Aeronautical Engineering (RDAE 2027)

Conference: 12–13 March 2027
Venue: Annasaheb Dange College of Engineering & Technology (ADCET), Ashta, Sangli, Maharashtra, India
Contact: rdae@adcet.ac.in

## Files

- `index.html` — website
- `styles.css` — styling
- `script.js` — mobile navigation, active-section highlighting, back-to-top button
- `assets/adcet-logo.png` — exact ADCET logo supplied by the organizer
- `assets/rdae-logo.png` — exact RDAE logo supplied by the organizer
- `assets/adcet-campus.jpg` — exact ADCET campus image supplied by the organizer

## Deployment

The site is static and can be hosted on GitHub Pages, Cloudflare Pages, Netlify, or similar services.

### GitHub Pages

1. Create a GitHub repository named `rdae2027`.
2. Upload all files and the `assets` folder.
3. Go to Settings → Pages.
4. Select deployment from the main branch/root.
5. Configure the custom domain `rdae2027.adcet.ac.in` when ADCET IT provides the DNS record.
